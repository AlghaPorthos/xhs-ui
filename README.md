# 📕 小红书风格 · 帖子详情 + 树形回帖 交互界面 Demo

一个纯前端的小红书(RedNote)风格界面原型:**图片 + 文字的帖子详情页 + 树形(多级嵌套)回帖**。

> ⚠️ 本项目仅作 UI/交互原型演示,无后端、无真实数据,所有内容为占位示例,与小红书官方无关。

## 🖼️ 界面构成

| 区域 | 内容 |
|---|---|
| 顶部导航 | Logo、搜索框、主导航、个人头像 |
| 左侧媒体区 | 3 张图片轮播(箭头 / 圆点切换,页码指示) |
| 右侧内容区 | 作者卡片(关注按钮)、标题、正文、话题标签、发布信息 |
| 互动栏 | 点赞 ❤️ / 收藏 ☆ / 评论数 / 分享 |
| 评论区 | **树形回帖**:一级评论 → 嵌套回复 → 三级以上缩进连线,"展开 N 条回复"折叠展开 |
| 底部输入栏 | 评论输入 + 发送(可发布演示评论)、@回复自动填入 |

## 🌲 树形回帖设计

- 一级评论为普通列表项
- 二级回复收纳在灰色圆角容器内,默认折叠,点击「展开 N 条回复」逐层展开
- 三级及更深回复以左侧竖线(缩进线)呈现层级,类似 Reddit 子线程
- 「作者」身份以蓝标徽章标识
- 任意评论点「回复」会自动在输入框填入 `@昵称`

## 🎭 演示交互(无需后端)

- 图片轮播切换、点赞/收藏数字与图标切换
- 回复树展开 / 收起
- 发送评论(回车或按钮),新评论插入列表顶部
- 关注 / 分享 / 表情等按钮给出 toast 反馈

## 🚀 运行

零依赖单文件,浏览器直接打开 `index.html`,或访问在线部署:

**https://alghaporthos.github.io/xhs-ui/**

## 🛠️ 技术

原生 HTML + CSS + JavaScript,单文件实现,响应式(桌面双栏 / 移动端单栏)。
